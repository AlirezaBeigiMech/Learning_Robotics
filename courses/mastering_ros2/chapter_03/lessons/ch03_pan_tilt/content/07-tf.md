## Check the live TF

**Check: Live TF** launches *your* `display.launch.xml` in the isolated grader. It then publishes joint
values you cannot predict and looks up `camera_link` in `base_link` from TF, the same lookup any ROS
node would do. The result must match the kinematics of the specification to within 2 mm.

The model checkpoint tests your file. This one tests that your **launch file, installation and running
system** really publish that model.
